# PharmaLink

منصة **B2B** إلكترونية تربط بين **مخازن الأدوية (الصيدليات)** و**شركات توريد الأدوية**، وتقوم على نظام **مناقصات إلكترونية (RFQ — Request For Quote)** يبدّل عملية طلب عروض الأسعار اليدوية بمسار رقمي منظّم وشفاف، بالإضافة لمسار شراء مباشر أبسط عبر كتالوج/سلة/طلب.

منشور فعليًا وقيد الاستخدام:
- **Backend**: Railway — `https://backend-production-6679b.up.railway.app`
- **Frontend**: Vercel — `https://pharma-b2b-two.vercel.app`

---

## آلية العمل

```
صيدلية تنشئ مناقصة (أصناف + كميات + موعد إغلاق)
        │
        ▼
موردون يقدّمون عروض أسعار — الأسعار مخفية عن الصيدلية حتى فتح المظاريف
        │
        ▼
إغلاق باب التقديم تلقائيًا عند الموعد المحدَّد
        │
        ▼
الصيدلية تفتح المظاريف عرضًا عرضًا (الأسعار تنكشف فرديًا)
        │
        ▼
تسجيل نقاط تلقائي: السعر + سرعة التوريد + تقييم المورد السابق + شركة معتمدة
        │
        ▼
الترسية على العرض الفائز → توليد أمر شراء (Purchase Order) تلقائيًا
```

إخفاء الأسعار قبل فتح المظروف **فعلي وليس شكليًا**: الحقول السعرية تُستبعَد من استجابة الـ API نفسها لأي عرض لم يُفتح بعد، فلا تصل للمتصفح أصلًا قبل أوانها.

## بنية المستودع

```
pharma-b2b/
├── backend/    Laravel 12 API (Sanctum, MySQL)
└── frontend/   واجهة ثابتة HTML/CSS/JS (Bootstrap 5.3، بدون build step) تتصل بالـ backend عبر REST API
```

المشروعان منفصلان تمامًا ويتواصلان فقط عبر HTTP — الفرونت إند لا يحتوي أي منطق أعمال، كل قرار (تفويض، حساب نقاط، حالة مناقصة) محسوم من الباك إند.

## الميزات

- **دورة مناقصات كاملة**: إنشاء → استقبال عروض → إغلاق تلقائي → فتح مظاريف → تسجيل نقاط → ترسية → أمر شراء.
- **نظام تسجيل نقاط موزون** بأربعة معايير قابلة للتخصيص لكل مناقصة (سعر، توريد، تقييم، اعتماد).
- **تسجيل حساب بخطوتين**: تحقق OTP عبر البريد قبل إنشاء الحساب فعليًا (لا حسابات معلّقة بإيميلات غير مؤكدة).
- **تسجيل دخول اجتماعي** عبر Google وFacebook.
- **تقييم الموردين** بعد اكتمال التوريد، يغذّي نظام التسجيل بالمناقصات اللاحقة، وتصنيف "شركة معتمدة" تلقائي (3 مناقصات فائزة فأكثر).
- **مسار شراء مباشر** (كتالوج منتجات → سلة → طلب) موازٍ لمحرك المناقصات لعمليات الشراء السريعة بدون تفاوض.
- **تقرير PDF** قابل للتحميل لكل مناقصة مُرسّاة.
- **واجهة ثنائية اللغة** (عربي/إنجليزي) بالكامل، واتجاه صفحة يتبدّل تلقائيًا (RTL/LTR).
- **وضع داكن/فاتح** قابل للتبديل الفوري.
- **متجاوبة بالكامل** مع الموبايل (قوائم منسدلة، جداول تتحول لبطاقات على الشاشات الضيقة).

## الأمان

المشروع خضع لتدقيق أمني شامل يغطي OWASP Top 10 والثغرات المنطقية الخاصة بمحرك المناقصات. أبرز ما هو مطبَّق:

- **Rate limiting** صارم (5 طلبات/دقيقة لكل IP) على كل مسارات التوثيق (دخول، تسجيل، OTP، استعادة كلمة مرور) لمنع هجمات التخمين.
- **تفويض عبر Laravel Policies** لكل عملية حساسة (ملكية المناقصة/العرض/الطلب)، مع فحص إضافي عند الكتابة (Defense in Depth) وليس فقط عند القراءة.
- **حماية من Race Conditions**: عملية الترسية محمية بقفل صفوف صريح (`lockForUpdate`) داخل transaction واحدة، تمنع ترسية نفس المناقصة مرتين بطلبين متزامنين.
- **حماية من IDOR**: كل مسار تعديل بيانات (تحديث حالة طلب، ترسية، فتح مظروف...) يتحقق من ملكية المورد/الصيدلية للمورد المطلوب قبل التنفيذ.
- **إخفاء بيانات حساس على مستوى الـ API** (لا الواجهة فقط) — أسعار العروض غير المفتوحة لا تُرسَل للمتصفح إطلاقًا.
- **حماية من XSS**: كل بيانات المستخدمين المعروضة بالواجهة تمر عبر تهريب HTML (`escapeHtml`) مركزي قبل الحقن بالـ DOM.
- **CORS مقيَّد** على دومين الواجهة الفعلي فقط، لا فتح عام.
- **منع تكرار العروض**: قيد فريد (Unique Constraint) على مستوى قاعدة البيانات يمنع تقديم نفس المورد أكثر من عرض على نفس المناقصة، بالإضافة لفحص تطبيقي.

## التشغيل محليًا

### المتطلبات
- PHP 8.2+, Composer
- MySQL (أو SQLite للتطوير السريع)
- أي خادم ثابت لتشغيل الفرونت إند (لا يحتاج Node/npm — بدون build step)

### الباك إند

```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

يعمل افتراضيًا على `http://localhost:8000`. متغيرات البيئة المطلوبة (`.env`) تشمل إعدادات قاعدة البيانات، `BREVO_API_KEY` لإرسال البريد، و`GOOGLE_CLIENT_ID`/`FACEBOOK_APP_ID` لتسجيل الدخول الاجتماعي (اختيارية — المشروع يعمل بدونها مع تعطيل تلك الميزة فقط).

لتفعيل الإغلاق التلقائي للمناقصات المنتهية محليًا:
```bash
php artisan schedule:work
```

### الفرونت إند

أي خادم ثابت يكفي:
```bash
cd frontend
php -S localhost:5500
```
ثم افتح `http://localhost:5500/index.html`. عدّل `API_URL` في `frontend/js/api.js` لو الباك إند يعمل على منفذ مختلف.

## المصادقة

Laravel Sanctum بنظام **Bearer Token** (وليس جلسات/كوكيز) — لا تأثير لاختلاف المنفذ (port) بين الفرونت والباك أثناء التطوير المحلي، ولا حاجة لإعداد CSRF لطلبات الـ API.

## النشر (Deployment)

- **Backend (Railway)**: نشر تلقائي من فرع `master` — كل `git push` يشغّل `php artisan migrate --force` ثم يبدأ السيرفر، مع `schedule:work` بالخلفية لتشغيل المهام المجدولة (إغلاق المناقصات المنتهية).
- **Frontend (Vercel)**: نشر تلقائي من نفس الفرع، جذر النشر (Root Directory) هو `frontend`.
